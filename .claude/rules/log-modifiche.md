# Log modifiche (`LOG.md`)

Ogni volta che lavori su questo repository (Marco o Roberto) e fai una modifica o decisione
reale — non un tentativo, non una bozza — aggiungi una voce in **`LOG.md` di questo repo**
(skill `/log-sessione`), nello stesso commit della modifica.

**Ordine: più recente in cima.** Se l'intestazione della data odierna esiste già, aggiungi la voce
sotto quella (in fondo alle voci già presenti per oggi); se non esiste, creala come prima sezione
subito sotto l'introduzione.

```
## 12/10/2026
### Marco
- 14:32 — <descrizione della modifica/decisione>
### Roberto
- 09:15 — <descrizione>
```

Le voci passate non si riscrivono. Un buon momento pratico: lo stesso istante di `git commit`.
